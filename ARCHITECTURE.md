# Architecture

The portfolio follows a progressive architecture strategy.

```text
Foundations
    ↓
SQL / Python
    ↓
Databases & Modeling
    ↓
ETL / ELT
    ↓
Cloud Data Platform
    ↓
Orchestration + Analytics Engineering
    ↓
Distributed Processing + Lakehouse
    ↓
Streaming
    ↓
IaC + CI/CD + Data Quality + Observability
    ↓
Enterprise Data Platform
```

The same business domain will be reused and evolved in later projects when this improves continuity and demonstrates architectural evolution.
