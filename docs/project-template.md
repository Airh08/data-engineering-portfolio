# Project Template

Every substantial project should document:

1. Business problem
2. Requirements and assumptions
3. Architecture
4. Data sources
5. Data contract / schema
6. Pipeline design
7. Implementation
8. Tests and data quality
9. Failure scenarios and recovery
10. Performance considerations
11. Local setup
12. Execution
13. Results
14. Trade-offs and future improvements

Recommended structure:

```text
project/
├── README.md
├── docs/
├── src/
├── tests/
├── data/
├── config/
└── infrastructure/
```
